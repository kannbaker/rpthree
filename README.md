# rpg-3js

## Runtime

- Node.js
- npm

## Client Setup

```bash
cd client
npm install
```

## Server Setup

```bash
cd server
npm install
cp .env.example .env
```

## Client Start

```bash
cd client
npm run dev
```

Client dev server: `http://localhost:3100/`

## Server Start

```bash
cd server
npm run build
npm start
```

Server default address: `http://localhost:3000/`
